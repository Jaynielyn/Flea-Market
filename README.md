# flea-market

# 概要
本プロジェクトは、Laravelを使用して開発されたECサイトです。商品閲覧、購入、レビュー投稿、ユーザー管理機能を備えています。AWSを活用してホスティングおよびストレージを管理し、CircleCIを用いた自動デプロイとテストが設定されています。

---

# 使用技術
- **フレームワーク**: Laravel
- **フロントエンド**: Bladeテンプレート
- **データベース**: AWS RDS (MySQL)
- **ストレージ**: AWS S3
- **認証**: Fortify
- **CI/CD**: CircleCI
- **ホスティング**: AWS EC2
- **決済**: Stripe

---

# 主な機能
1. **商品一覧表示**
   - おすすめ商品とマイリストを切り替え表示。
2. **検索機能**
   - 商品名、カテゴリでの検索。
3. **購入機能**
   - クレジットカード、コンビニ払い、銀行振込対応。
4. **レビュー機能**
   - 商品に対するレビュー投稿と表示。
5. **いいね機能**
   - 商品のお気に入り登録と「マイリスト」表示。
6. **管理者機能**
   - ユーザーとコメントの管理、メール送信。

# 環境構築手順

# 1. 前提条件
- macOS
- Composer
- PHP >= 8.1
- MySQL
- AWS CLI

---

# デプロイ手順

# 1. AWS環境の設定
- EC2インスタンスを起動し、SSH接続。
- S3バケットとRDSを作成。

# 2. アプリケーションのアップロード
```
scp -i ~/Downloads/Test.pem -r ./flea-market ec2-user@98.84.132.16:/var/www/
```

# 3. CircleCIの設定
- `.circleci/config.yml` を編集。
- CircleCIプロジェクトをGitリポジトリに接続。
